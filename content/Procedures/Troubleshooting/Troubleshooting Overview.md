Welcome to the Landfall support knowledge base. If you're experiencing technical issues while playing, start here. Below you'll find detailed guides for resolving common problems, from memory allocation to diagnosing network lag.

## **What You’ll Find Here**
- [[Changing Allocated RAM in Modrinth Launcher]]: If your game is lagging, stuttering, or crashing with "Out of Memory" errors, your modpack likely needs more RAM than the default. This is a guide to change RAM settings globally or per modpack.
- [[Submitting Logs & Crash Reports]]: To help us troubleshoot crashes or strange behavior, we need your log files. This is a step-by-step guide for locating and sending your `latest.log` and crash reports.
- [[Running an MTR]]: If you're experiencing rubberbanding, disconnects, or unexplained lag, your connection to the server might be the issue. This guide will explain how to use `mtr` or WinMTR to run a diagnostic and send us the report.

**If you're unsure where to begin, start with logs! They’re always helpful.**
